# Privacy Policy — Agent Access Audit

_Last updated: 12 November 2026_

This plugin is a set of instructions (skills) that runs inside Claude. It has no servers of its own.

- **No data collection.** The plugin author does not receive, store or process your configuration, code or reports.
- **What Claude reads.** Within your Claude session, Claude reads agent configuration files in the projects and folders you give it access to. These files can contain secrets; the plugin instructs Claude never to print more than the first 4 characters of any secret. Processing happens under Anthropic's terms and privacy policy.
- **Files the plugin may create, only with your confirmation:** a baseline report (`AGENT_ACCESS_BASELINE.md`, secrets masked) and backups of configuration files you agree to change. They stay in your project.
- **No storage elsewhere, no third parties, no tracking.**

Questions: https://github.com/xelA31B/agent-access-audit/issues
